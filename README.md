# COME BY

A simple mobile-first marketplace prototype: clients post lawful companionship/assistance requests, available providers show interest, and the client chooses who to connect with.

## Current prototype
- Client and provider modes
- Requests and proposed amounts
- Interest / offer flow
- Local demo data
- Mobile-first UI
- PWA install manifest
- Browser geolocation permission and session location-sharing UI
- No payments or transaction processing
- No connection fee

## Production work still required
- Secure backend/database
- Authentication and identity verification
- Real-time request matching
- Real-time chat
- Real-time location sharing with consent and expiry
- Push notifications
- Report/block/moderation tools
- Emergency/safety workflows
- Terms, privacy policy and local legal review
- App-store packaging and signing

The app should be positioned for lawful, non-sexual companionship, event/tour assistance, errands and personal assistance unless the platform is legally reviewed for any other category.
